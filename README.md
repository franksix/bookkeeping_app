<h1>下载源码步骤：</h1>
<h3>1.打开资源管理器</h3>
<h3>2.进入想要存放项目的文件夹</h3>
<h3>3.点击地址栏空白位置</h3>
<h3>4.输入“cmd”后Enter</h3>
<h3>5.输入“git config --global user.name &lt;此处填写网名&gt;”后Enter</h3>
<h3>6.输入“git config --global user.name &lt;此处填写电子邮箱&gt;”后Enter</h3>
<h3>7.输入：“git clone https://gitcode.com/frank_mia/bookkeeping_app.git”后Enter</h3>
